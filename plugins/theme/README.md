# plugins/theme/ — 自开发的第三方主题

主题 = **一个只声明设计令牌的 CSS 文件**。它不写任何选择器、不写组件样式，
因此改主题**不可能**把界面改歪（尺寸、间距、位置全部住在组件 CSS 里）。

## 本目录现有的五个主题

| 文件 | 名称 | 模式 | 一句话 |
| :--- | :--- | :--- | :--- |
| `glass-dark.css` | 玻璃拟态 · 深色 | dark | 午夜极光 + 磨砂玻璃：紫/青/品红/湖绿光斑打底，面板半透明 + 34px 模糊 + 1.9 饱和度 |
| `glass-light.css` | 玻璃拟态 · 浅色 | light | 晨雾 + 磨砂玻璃：低饱和粉彩光斑，半透明白面板 + 30px 模糊，亮白高光 + 冷灰投影写出玻璃厚度 |
| `vibrant-dark.css` | 活力满满 · 深色 | dark | 深夜霓虹 + 硬朗快节奏：珊瑚/品红/琥珀高饱和光带，面板是实心硬壳（14px 模糊），动效 190ms 带回弹 |

## 主题文件怎么写

复制 `frontend/src/styles/themes/_template.css`（令牌的**完整清单**，按组列全）改名字即可。
文件头可以写三条指令，供程序读出主题名 / 深浅模式 / 色板缩略图：

```css
/* @theme-name 玻璃拟态 · 深色
   @theme-mode dark
   @theme-swatch #070a14 #121a2b #8ab4ff #eaf0ff #22d3ee */

:root[data-theme="glass-dark"] {
  color-scheme: dark;
  --bg-app: #070a14;
  --accent: #8ab4ff;
  /* …只写你想改的令牌，没写的自动回退 tokens.css 的默认值 */
}
```

- 选择器里的 `data-theme` 值就是主题 id（**与文件名一致最省事**）；
- 不写指令也能用：名称取文件名，模式按文件名里的 `dark/light` 或 `深色/浅色` 猜；
- 令牌缺省即回退，所以一个主题文件可以很短。

## 写主题时的几条硬约束

1. **只声明令牌，不写选择器与组件样式。** 组件的视觉全部走 `var(--token)`，
   你在主题里写死一个 `background` 只会制造「同一处视觉有两个来源」——
   改主题时那处不动，而且要读选择器特异性才知道为什么。
2. **不要覆盖 `--bg-window`**：它由 `tokens.css` 从 `--bg-app` 派生。
3. **布局令牌一般别动**（`--h-titlebar` / `--w-sidebar` / `--h-playerbar` /
   `--h-header` / `--row-h`）：它们决定固定布局，改了会移动元素。
   圆角与动效令牌（`--r-*` / `--dur` / `--ease`）属于视觉，随便改。
4. **深浅模式要写对**：`color-scheme: light|dark` 会影响原生控件（滚动条、
   输入框）的绘制；`@theme-mode` 只影响设置页卡片上的标签。
5. **对比度自查**：`--accent` 有两个用途 —— 实底按钮的底色（配 `--accent-text`）
   与部分色用文本。两处都要 ≥ 4.5:1。本目录四个主题的取值：
   `#8ab4ff` 9.5:1、`#4f5bd5` 5.5:1、`#ff7a59` 8.5:1、`#c9247a` 5.2:1（对各自窗口底）。
6. **浅色主题的 `--slider-idle-filter` 不要用「压暗」**：它作用在底栏进度条的
   强调色填充与手柄上，压暗在浅底上等于「更抢眼」，与「未聚焦时退到后面」相反。
   本目录的浅色主题用的是降饱和 + 提亮（`saturate(0.45) brightness(1.12)`）。
7. **玻璃类主题必须让 `--bg-canvas` 有内容**：面板的 `backdrop-filter` 只能糊
   「背后真的有的东西」。底色一旦压成纯色，模糊半径再大也只是块灰板。

## 安装

```powershell
Copy-Item plugins\theme\*.css "$env:APPDATA\LocalMusicPlayer\themes\" -Force
```

然后设置 → 外观 → 「重新扫描主题」。主题目录是**平铺**的，不支持子目录。

也可以不用命令行：设置 → 外观 → 「添加自定义主题」里有「从仓库获取」这一页，
装上就是最新版，已装的会标「已安装」，远端版本更高时按钮变成「更新」。
（那一页读的是本目录的 `index.json` —— 改完这里的 CSS 记得跑一次
`node plugins/build-index.mjs`，否则客户端看到的还是旧版本，详见 `plugins/README.md`。）
