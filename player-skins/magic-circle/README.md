# 魔法阵舞台（magic-circle）

世界地图 + 运镜版的歌词舞台：**歌词钉在世界坐标上不动，镜头飞过去看它。**

```
World (12000 × 12000)
 ├─ Layer 0  背景星域        视差 0.2
 ├─ Layer 1  巨型底阵        视差 0.5（R=5600，贯穿全图的地基）
 ├─ Layer 2  连接光路        节点之间的路径（飞行时会亮起来）
 ├─ Layer 3  歌词节点 × N    世界坐标固定
 └─ Layer 4  世界粒子 0.9 → 屏幕粒子 → 白闪 / 暗角

Camera (x, y, zoom, rot)
 └─ 每帧按「当前高亮节点」插值；换句 = 运镜 = 转场
```

全部动效只有**一个**输入：`ctx.spectrum()` 给的 128 段对数全谱。

## 文件

| 文件               | 作用                                                 |
| ------------------ | ---------------------------------------------------- |
| `skin.json`        | 清单（能力声明 / 配色声明 / 排序）                   |
| `skin.js`          | 插件入口：生命周期、帧循环、节点状态机、交互         |
| `skin.css`         | 舞台与 HUD（宿主会包成 `@layer skin { @scope(…) }`） |
| `lib/config.js`    | **所有可调参数**（想手调路径就改这里）               |
| `lib/layout.js`    | 歌词 → 分段 → 节点世界坐标 → 入场运镜                |
| `lib/camera.js`    | 相机：跟随 + 五种运镜 + 呼吸微动                     |
| `lib/spectrum.js`  | 128 段全谱 → 三套平滑 + 五个频段 + 质心 + 通量       |
| `lib/render.js`    | 全部绘制（底阵 / 刻度环 / 符文 / 文字 / 粒子）       |
| `lib/particles.js` | 双层粒子池（预分配 Float32Array，运行期不 new）      |
| `lib/util.js`      | 缓动 / 数学 / 稳定随机                               |

## 六种运镜（按**时间间隔**自动选，不按“看起来多远”）

| 类型               | 触发条件                                          | 时长  | 缓动                            |
| ------------------ | ------------------------------------------------- | ----- | ------------------------------- |
| `pan` 平移         | 两节点距离 ≤ 520（几乎原地）                      | 0.35s | easeInOutCubic                  |
| `dash` 快切        | 间隔 < 3.5s —— **绝不拉远**，短间隔专用           | 0.5s  | 前 70% easeIn、后 30% easeOut   |
| `arc` 弧线         | 3.5s ≤ 间隔 < 6.5s                                | 1.05s | easeInOutQuint（zoom 先缩后放） |
| `zoomOut` 拉远俯瞰 | 间隔 ≥ 6.5s —— **只给长间隔**（设计稿那套三段式） | 1.9s  | 前半 easeOut、后半 easeIn       |
| `rotate` 旋转入场  | 每个副歌段的第一句（定点，无条件）                | 0.9s  | easeOutBack（螺旋切入）         |
| `pass` 穿越式      | 全曲最后一个副歌的第一句（唯一一次白闪）          | 1.0s  | 前 0.7 easeIn、后 0.3 easeOut   |

`zoomOut` 型的定点（桥段 / 尾奏）还要再过一道「间隔 ≥ 6.5s」的闸：段首恰好紧跟一句
短间隔时改走上面的分档 —— 使用者明确要过：**短间隔不要“放大 → 移动 → 缩小聚焦”**。

转场时长 = 镜头飞行时长 = **开口前的提前量**，三者是同一件事，所以**不需要**额外的场景切换逻辑。

### 提前量（这次改动的核心）

镜头**抢跑**：在这一句开口前 `leadFor(gap)`（间隔 × 0.4，夹在 0.3~~1.25s）就开始飞，
飞完正好是开口那一刻。短间隔（2~~3 秒一句）如果等开口才起飞，词都唱到一半还在飞，
动画就“跟不上速度”；把起飞时间提前到开口之前，矛盾就没有了。
判定逻辑是纯函数 `lib/layout.js → focusAt()`，smoke 里有断言。

## 节点排布（一句歌词 = 一个节点，距离 ∝ 时间间隔）

```
step  = clamp(820, 430 × 间隔秒, 3200)      长留白（≥13s）→ 4600
半径  = 沿一条平滑鼓起的螺旋（内圈 → 中段外扩 → 收回内圈）
夹角  = 由三边反解  cosΔ = (r₁²+r₂²−step²)/(2·r₁·r₂)   ⇒ 直线距离严格 = step
```

- **一句歌词一个节点**，下标与 `lyrics().index` 严格一一对应（空文本的行也不丢，
  丢一行后面的行号就全错位了）；
- 半径每步最多挪 `step` 的 45%，保证“距离由间隔说了算”，不会出现
  “唱上一句还没飞到就换下一句”；
- 半径下界 `0.78 × step`：否则 cos 会被夹到 −1，相邻两句在两个点上来回弹。

分段（主歌 / 预副歌 / 副歌 / 桥段 / 尾奏）仍然会算，但**只用来**：HUD 上的段落标签

- 两处定点运镜（副歌 rotate、最后一个副歌 pass）。段数 ≥ 3 时最后一段判为尾奏，
  最后一句永远落回阵心 `(0,0)`。

想给某首歌手调：打开 `lib/config.js`，把 `LAYOUT.nodes` 换成自己的数组

```js
export const LAYOUT = {
  nodes: [
    { x: 900, y: -600, zoom: 1.0, lyric: "第一句歌词", transition: "pan" },
    { x: -2800, y: 0, zoom: 1.2, lyric: "副歌第一句", transition: "zoomOut" },
    { x: 0, y: 0, zoom: 0.6, lyric: "最后一句", transition: "zoomOut" },
  ],
  …
};
```

`lyric` / `transition` / `zoom` 都可以省略（分别按行号对齐、按距离自动选、按歌词长度反算）。

## 歌词是**预渲染**的

镜头一出发（`onFocus`）就调 `render.prewarm(node, zoom)`：排版 + 把每个字画成
带蓝光的位图缓存在节点上，于是**镜头还在路上，字已经渲染好了**，落地那一刻直接是
成品，不会再看到“字还在路上拼”糊掉的画面；运行期每帧只剩 `drawImage`。
位图只有主角 / 正在碎的节点才持有，碎完（`passing → idle`）立刻释放。

## 128 段频谱怎么驱动画面

| 频谱量     | 驱动对象                                                   |
| ---------- | ---------------------------------------------------------- |
| `fast[i]`  | 高亮节点外环第 i 根刻度的长度 / 亮度（镜像成 256 根）      |
| `mid[i]`   | 中环符文（逐个点亮，像跑马灯）、内核几何                   |
| `slow[i]`  | 节点整体缩放（`bass`）、中环转速（`low`）、光晕（`total`） |
| `high`     | 灵光粒子生成速率、星尘闪烁                                 |
| `centroid` | 整体色相偏移 ±20°（低频暖 → 高频冷是刻度本身的渐变）       |
| `flux`     | 超阈值 + 冷却 → 涟漪扩散 + 灵光爆发                        |
| `peak[i]`  | 刻度顶部的亮帽（峰值保持）                                 |

同一份数据走**三套时间平滑**（0.6 / 0.15 / 0.03），刻度、符文、光晕看起来像三种东西。

## 约束遵守情况

- 零裸包名 import，只 import 本包目录内的相对模块；
- **子模块用 `await import(...)` 并透传 token**：`/skins/` 是逐文件鉴权的，
  而 ES 模块解析相对说明符时只保留路径、丢掉 `?t=`，写成静态 `import` 会
  让 `lib/*.js` 全部 403（报错还挂在入口上）。每个文件顶部那两行就是干这个的，
  **不要改回静态 import**。宿主侧的根因修复见 `internal/skins`（带 token 的
  响应签 `Path=/skins` 的会话票，子资源凭票放行），两边任一成立都能加载；
- 只有一条 `requestAnimationFrame` 帧循环（暂停 9 秒自动停帧，宿主补丁会拉起来），
  没有 `setInterval` 轮询、没有网络请求、没有 `eval`；
- 不碰 `window` / `document.documentElement`；
- 频谱是拉取式：在自己的帧循环里现取（清单已声明 `capabilities.spectrum`）；
- `destroy()` 里取消帧循环、摘掉指针监听、清空粒子池与 DOM。

## 安装

1. 把整个 `magic-circle/` 目录拷进 `<数据目录>/player-skins/`；
   （Windows 下通常是 `%APPDATA%\LocalMusicPlayer\player-skins\magic-circle`）
2. 打开「设置 → 播放界面样式 → 重新扫描样式」；
3. 点按钮组里的「魔法阵舞台」。

也可以在设置页点「导入样式」直接选这个目录（同名已存在时会拒绝覆盖）。
