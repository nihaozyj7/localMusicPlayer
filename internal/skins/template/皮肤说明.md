# 播放界面样式（插件）

这个目录里的每个**子目录**都是一个样式插件。应用启动时扫描一次，
在「设置 → 播放界面样式」里点「重新扫描样式」可以立刻重扫。

内置样式与你自己写的样式走**完全一样**的加载路径：应用自带的经典 / 沉浸
放在安装目录的 `resources/player-skins/` 下（只读），你放在这里的这份是
「用户自己写的」（可改、可删）。所以你可以直接把内置样式的目录整份拷过来当起点。

## 目录结构

```
player-skins/
  _template/          示例插件（下划线开头 = 不参与扫描，复制它改个名就能用）
    skin.json         清单（必需）
    skin.js           入口（必需，清单里的 entry 可改）
    skin.css          外观（可选，清单不写 styles 时会自动带上目录里顶层的 *.css）
    assets/icon.svg   自带图标（可选；不写就用宿主图标）
    lib/…             自带的私有模块（可选；只允许插件目录内的相对 import）
  aurora/             你自己的样式（目录名 = id）
```

> 下划线 / 点开头的目录不会被扫描（`_template` 就是靠这条不出现按钮组里）。

## 三条硬规则

1. **零 import**：不要 import 应用的任何模块（`store` / `utils` / `bridge` /
   `@localmusicplayer/player-skins` 等），也不要用相对路径去够别人目录里的文件。
   公共零件从 `ctx.sdk` 拿（见下）。
2. **不用自己写 CSS 作用域前缀**：宿主会把你的 CSS 包成
   `@layer skin { @scope (<你的舞台>) { … } }` —— 你写不到标题栏 / 底栏 / 浮层，
   也不会污染别的界面。同时 `@layer skin` 让你压不过宿主壳（那本来就不该你管）。
3. **在清单里声明 `colors`**：宿主用它决定**自己的**控件栏与浮层配色，
   并保证对比度可读。跟随宿主主题的样式写 `{ "theme": true }` 即可；
   缺了也不报错，但会在设置页的样式卡片上出现一个警告图标。

## 清单（skin.json）

```json
{
  "id": "aurora",
  "name": "极光",
  "version": "1.0.0",
  "apiVersion": "3.0",
  "author": "你的名字",
  "description": "一句话说明",
  "entry": "skin.js",
  "styles": ["skin.css"],
  "icon": { "file": "assets/icon.svg" },
  "order": 200,
  "capabilities": { "spectrum": true, "background": true, "interactive": true },
  "colors": { "bg": "#0b1020", "fg": "#f2f4ff", "accent": "#7aa2ff" },
  "performance": { "budgetFps": 45 }
}
```

| 字段 | 说明 |
| --- | --- |
| `id` | 必须与目录名一致 |
| `apiVersion` | 契约版本。`major` 必须与宿主相同；`minor` 可以比宿主旧（宿主 3.2 能跑声明 3.0 的插件） |
| `entry` | 入口模块，默认 `skin.js` |
| `styles` | CSS 文件（相对插件目录）。不写就自动带上目录里顶层的 `*.css` |
| `icon` | `{"file":"assets/icon.svg"}` 自带图标（推荐）；也可 `{"sprite":"disc"}` 用宿主图标 |
| `order` | 按钮组排序：内置是 10~90，第三方建议 ≥ 200 |
| `capabilities.spectrum` | 要用实时频谱就写 `true`。数据是**拉取式**的（`ctx.spectrum()`，固定 128 段全谱、读到才采样）；不声明就一次都收不到、宿主也一次都不采 |
| `capabilities.background` | 需要整窗背景层（`ctx.backgroundRoot`）。声明后宿主会把标题栏/底栏/侧边栏退成半透明 |
| `capabilities.interactive` | 默认 true。`false` 表示宿主可能把你挂到"只能看"的舞台（桌面背景歌词窗口） |
| `colors.bg` / `colors.fg` | **你的画面**的主底色 / 前景色。宿主据此决定自己的控件栏用深色还是浅色，并在对比度不足时自动纠正 |
| `colors.theme` | 画面跟随宿主主题（与 bg/fg 二选一）。内置的经典 / 沉浸就是这么声明的 |

## 入口（skin.js）

```js
export default {
  id: "aurora",          // 与清单一致（可不写）
  mount(ctx) {},         // 必需：往 ctx.root 写 DOM
  update(ctx, patch) {}, // 可选：宿主推来的增量更新
  destroy(ctx) {},       // 可选：清定时器 / 监听 / 引用
};
```

**接口速查**

```
ctx.root / ctx.backgroundRoot
ctx.track()      { id, title, artist, album, duration, kind }
ctx.media()      { song, cover, covers, coverIndex, lyrics }     ← 聚合快照
ctx.lyrics()     { lines, index, status, statusText, source, text }
ctx.covers()     { list, index, current }
ctx.playback()   { position, duration, playing, volume, muted }
ctx.options()    { showLyrics, lyricsFontSize, animations, coverCarousel, …, interactive }
ctx.env()        { themeId, mode, width, height, dpr, reducedMotion, foreground }
ctx.spectrum()   { bands: Float32Array(128 段对数全谱, 0..1), at: 采样时刻 } | null
                 ← 拉取式：调用才采样（~30Hz 节流）；没在播放 / 没声明能力 = null
ctx.sdk          createLyricsView / createFxLyrics / createCamera / createBackgroundLayer /
                 applyFit / parseLrc / findLyricIndex / formatLrcTime /
                 html.{EMPTY_TRACK,escapeHtml,setCoverImage,subtitleOf,lyricsEmptyText} / util.{clamp,debounce}
ctx.actions      seek(ms) / seekBy(ms) / seekRatio(0..1) / togglePlay / next / prev /
                 toggleLike / openFolder / openCoverPanel / openLyricsPanel / reportBackdrop({bg,fg})
ctx.on(type, fn) 订阅一次更新（返回退订函数）
ctx.defaultCover / ctx.themeId / ctx.mode
```

`update(ctx, patch)` 与 `ctx.on(type, fn)` 收到同一份 patch，`patch.type` 取值：

| type | 载荷 | 什么时候来 |
| --- | --- | --- |
| `mount` | 全量快照 | 挂载之后立即一次 |
| `song` | `{ song, cover, covers, coverIndex, lyrics }` | 换歌 |
| `media` | `{ cover, covers, coverIndex }` | 封面变化 / 轮播切图 |
| `lyrics` | `{ lyrics }` | 歌词装载完成或匹配状态变化 |
| `progress` | `{ position, duration, playing, lyricIndex }` | 播放进度（已按帧节流） |
| `state` | `{ playing, volume, muted }` | 播放 / 暂停 / 音量 |
| `options` | `{ options }` | 设置项变化 |
| `theme` | `{ themeId, mode }` | 主题 / 深浅色变化 |
| `resize` | `{ width, height }` | 舞台尺寸变化 |
| `visibility` | `{ foreground: boolean }` | 详情页开关（据此停帧） |
| `chrome` | `{ fg, bg, accent }` | 宿主壳配色算好了（只读对拍用） |
| `close` | — | 详情页关闭 |
| `destroy` | — | 即将卸载（`destroy` 之前最后一次） |

不确定某类更新时，直接用 `ctx.track()` / `ctx.lyrics()` / `ctx.playback()` 现取快照 ——
**任何一次推送之后，快照与刚推的载荷一定一致**。

**实时频谱没有补丁**：它是拉取式 `ctx.spectrum()` —— 在你自己的更新/帧循环里现取，
调用才会触发采样（不调 = 零开销，固定 128 段全谱、约 30Hz 刷新一次缓存）。
返回 `null` 有三种原因：没在播放、刚开播样本还没攒够、清单没声明
`capabilities.spectrum`（最后一种控制台会提醒一次）。`at` 是采样时刻，
连续两帧读到同一个 `at` 是正常的。

## 排错

- 按钮组里没有你的样式：确认目录里有 `skin.json` + `entry` 指向的入口文件，
  且目录名不以 `_` / `.` 开头；
- 出现了但点开没变化：按 F12 看控制台，宿主会打印加载失败的原因；
  设置页的「播放界面样式」卡片里也会列出失败原因；
- 样式卡片上有警告图标：说明清单里的 `colors` 缺失或写法不对（悬浮看原因），
  宿主已降级用主题配色画自己的控件栏；
- 改了没生效：`/skins/` 的响应带 `no-store`，不会缓存；如仍是旧的，点一次
  「重新扫描样式」。

自带图标、贴图、字体的路径都相对插件目录写（`assets/bg.png`），
不能引用网络资源（CSP 会拦）。
