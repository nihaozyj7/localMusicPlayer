# docs/archive —— 历史文档存档

这里的文件**不是当前事实来源**，全部是针对**当时那个代码快照**的一次性审查 / 修复记录。
它们被归档的原因是同一个：文中描述的架构、文件、行号已经变了，留在 `docs/` 根目录
会被下一位读者（人或 AI）当成「现在就是这样」，从而做出错误的判断与改动。

## 归档规则

| 归档 | 保留在 `docs/` |
| :--- | :--- |
| 对某个代码快照做**审计**的结论（含问题清单、`文件:行号`） | 规定**产品现在怎么做、为什么**的设计与实现说明 |
| 针对该审计的**修复记录** | 需求原文、契约定义、开发约定 |
| 已被后续方案取代的诊断 / 耦合报告 | 仍然成立的根因分析与踩坑记录 |

判断标准只有一条：**读完之后照做，会不会做错。**

## 注意

- 归档时路径变了，文内相对的 `docs/xx` 链接可能仍指向旧位置；这些链接**按当时**的意思读。
- `review/scripts/*.mjs` 是当时用来统计引用数的**一次性**脚本，依赖当时的目录形状，
  现在不一定跑得起来 —— 它们是证据留档，不是可复用的工具。
- 需要当前的工具清单，看 `docs/19-开发说明.md`；需要当前的设计约束，看仓库根 `AGENTS.md`。
