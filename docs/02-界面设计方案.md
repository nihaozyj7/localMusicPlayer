# 界面设计方案 v1

> 依据：`docs/01-需求原始记录.md`
> 技术形态：Go + Wails3（WebView2 前端为原生 HTML/CSS/JS，无框架）
> 视觉基调：黑白极简 + 毛玻璃拟态（Glassmorphism）

---

## 1. 设计原则

1. **样式与结构彻底分离**：HTML 中不写任何内联 `style`，不写 `<style>` 块。所有视觉来自 `frontend/src/styles/`。
2. **主题即 CSS 文件**：一个主题 = 一个 CSS 文件，只声明设计令牌（design tokens），通过 `:root[data-theme="文件名"]` 生效。用户丢进目录即可用。
3. **布局固定**：窗口骨架为固定三区（顶栏 / 内容 / 底栏），任何界面切换都不改变骨架位置，避免「页面跳动」。
4. **一份控件到处用**：底部播放控件在主界面与三个播放界面中共用同一个 DOM 组件，只有尺寸变量不同。
5. **毛玻璃只用变量控制**：模糊强度、透明度、边框高光全部令牌化，主题作者可逐项覆盖，不需要碰组件 CSS。

### 层级（z-index）

| 层 | 内容 | z-index |
| --- | --- | --- |
| 背景层 | 渐变光斑 / 封面虚化 | 0 |
| 主内容 | 侧边栏 + 内容区 | 10 |
| 底部控件 | PlayerBar | 40 |

## 3. ① 标题栏

- 高 36px，左侧应用名 + 当前视图名（如 `音乐播放器 · 沉浸`），中部可拖拽，右侧窗口按钮。
- `-webkit-app-region: drag` 由 Wails3 frameless 支持；按钮区域 `no-drag`。
- 右上角：主题切换（☾/☀）、最小化、最大化、关闭。

---

## 4. ② 侧边栏

- 宽 232px，`position: sticky`，独立滚动，毛玻璃面板。
- 结构：
  - **库**：所有歌曲（含曲目数徽标）、播放列表（含队列数徽标）、重新扫描（次要入口，主入口在内容头部）。
  - **歌单**：列表；`我喜欢` 固定第一项，`data-locked="true"` → 无删除按钮、禁用右键删除。
  - 底部：`＋ 新建歌单`、`设置`。
- 选中态：整行高亮 + 左侧 3px 主题色指示条 + 背景毛玻璃加深。
- 拖拽：歌单可拖动排序（自定义歌单之间），「我喜欢」不可拖动。

## 5. ③ 主内容区

### 5.1 内容头部 ContentHeader

- 高 64px，粘性（sticky），下滑时以毛玻璃遮住下方内容。
- 左：视图标题 + 副标题（如「所有歌曲 · 1,248 首」）。
- 右：工具条，按视图动态显示：
  - 搜索框（所有歌曲 / 歌单）
  - **重新扫描** 按钮（B2，所有歌曲视图常显）
  - 排序下拉（标题 / 歌手 / 专辑 / 时长 / 添加时间）
  - 视图密度切换（舒适 / 紧凑）（可选）
  - 播放全部 / 随机播放

### 5.2 曲目表格 TrackTable（所有歌曲 / 播放列表 / 歌单 共用）

列（固定布局，百分比 + 定宽混合）：

| 列 | 宽度 | 说明 |
| --- | --- | --- |
| 拖拽手柄 | 28px | 仅播放列表视图显示（B4） |
| 序号 / 播放态 | 40px | 悬停变播放按钮；正在播放显示跳动音柱 |
| 封面（小） | 40px | 32×32 圆角 |
| 标题 | flex 1fr | 主行标题，次行歌手 |
| 专辑 | 1fr | 可隐藏 |
| 时长 | 72px | 右对齐等宽数字 |
| 爱心 ♥ | 44px | **所有歌曲视图**必显（B7）；歌单视图高亮显示「已在该歌单」 |
| 更多 ⋯ | 40px | 菜单：加入播放列表 / 加入歌单 / 从列表移除 / 在文件夹中显示 |

- 行高：舒适 56px / 紧凑 44px。
- 斑马纹关闭，改用极低对比分隔线；悬停整行毛玻璃高亮。
- 正在播放行：左侧主题色指示条 + 标题主题色。
- 拖拽排序：HTML5 draggable 或指针事件实现，拖动时显示半透明浮层 + 插入位置指示线。

### 5.3 设置面板（视图 `settings`）

内部为**分区 + 卡片**结构，不换页：

1. **音乐文件夹**（A1/A2）
   - 路径列表：路径 + 状态（监听中 / 不存在 / 无权限）+ 曲目数 + 移除按钮。
   - `添加文件夹`（调用系统目录选择）、`立即重新扫描`。
   - 开关：`启动时自动扫描`、`实时监听文件夹变化`。
2. **过滤规则**（A3/A4）
   - 规则行：`类型(大小/正则) | 条件(<,>,=) | 值 | 作用(排除/仅包含) | 启用开关 | 删除`。
   - 预置示例：「排除小于 10KB 的文件」「排除匹配 `\.mp4$` 的文件」。
   - 支持规则组合预览：下方显示「当前规则将过滤 N 首中的 M 首」。
3. **外观**（A5/A6/A8）
   - 主题模式：浅色 / 深色 / 跟随系统。
   - 主题文件选择卡片列表（自动扫描主题目录，展示主题名 + 色板缩略）。
   - 毛玻璃强度滑杆（模糊半径）、透明度滑杆、动画开关。
   - `打开主题文件夹` 按钮。
4. **播放**：默认循环方式、音量记忆、淡入淡出、无缝衔接（可选）。
5. **歌词**：来源优先级、字号、居中高亮行数。
6. **关于 / 数据**：曲库缓存位置、清空缓存、版本信息。

## 6. ④ 底部常驻播放控件 PlayerBar

高 88px，固定底部，毛玻璃，顶边 1px 高光。

```
┌──────────────────────────────────────────────────────────────────────────────────────┐
│  ┌────┐  歌名 ♥            ┌─────┐  ┌───┐  ┌─────┐  01:23 ──●──────────── 04:05      │
│  │cover│ 歌手 · 专辑        │ ⏮  ▶  ⏭ │       │  🔊 ────  ⧉ ⇄  ☰  ⛶  │
│  └────┘                    └─────┘                │
└──────────────────────────────────────────────────────────────────────────────────────┘
   左区 320px                  中区 flex                 右区 320px
```

- **左区**（B10）：48×48 封面（缺省为占位图）、歌名、歌手·专辑、爱心按钮、点击空白处进入播放界面。
- **中区**（B11/B13/B14）：上一曲 / 播放暂停（主按钮 40px 圆形主题色）/ 下一曲；下方为进度条：已播时间 + 可拖动轨道 + 总时长。悬停轨道加粗并显示拖拽手柄的气泡时间。
- **右区**（B12/B15）：音量图标 + 音量滑杆（悬停展开）、循环方式按钮（顺序 → 列表循环 → 单曲循环 → 随机，循环点击）、播放界面切换（经典/沉浸/简约 弹出选择）、沉浸全屏。

## 7. 播放界面 PlayerView（三种样式）

进入方式：点击底栏封面/歌名、底栏 ⛶ 按钮、双击曲目。

统一结构：`PlayerView{ Header(返回 + 标题 + 样式切换) / Stage(样式区) }`，底部仍是共用 PlayerBar。

### 7.1 经典 Classic

```
┌────────────────────────────────────────────────────────────┐
│  ← 返回                        经典 | 沉浸 | 简约           │
│  ┌──────────────────┐   ┌────────────────────────────────┐ │
│  │                  │   │  歌词滚动区（右对齐/居中）      │ │
│  │   ● 旋转唱片      │   │  当前行高亮放大 + 主题色        │ │
│  │   320 ~ 420px    │   │  上下行渐隐                     │ │
│  │                  │   │                                │ │
│  └──────────────────┘   └────────────────────────────────┘ │
│  ─────────────── PlayerBar ───────────────                 │
└────────────────────────────────────────────────────────────┘
```

- 左：唱片 = 封面上叠一层黑色黑胶纹理 + 中心轴孔，`animation: spin 24s linear infinite`，暂停时 `animation-play-state: paused`（C2）。
- 右：歌词滚动，靠左对齐更利于阅读；当前行字号 ×1.25、字重加粗、主题色，其余行透明度 0.4。

### 7.2 沉浸 Immersive

```

┌────────────────────────────────────────────────────────────┐
│  ← 返回                        经典 | 沉浸 | 简约           │
│                                                            │
│      [ 封面铺满整个窗口 + 高斯模糊 + 暗化遮罩 ]              │
│                                                            │
│              ┌──────────────────────────┐                  │
│              │      中间显示歌词          │                  │
│              │      当前行高亮            │                  │
│              └──────────────────────────┘                  │
│  ─────────────── PlayerBar（毛玻璃）───────────────         │
└────────────────────────────────────────────────────────────┘
```

- 背景层：同一张封面 `object-fit: cover` 铺满 → `filter: blur(48px) saturate(1.4)` → 叠一层 `rgba(0,0,0,.35)`（浅色主题为 `rgba(255,255,255,.35)`）保证文字对比度（C3）。
- 歌词居中，行间距放大（2.2），当前行两侧加光晕；歌词容器自身也是毛玻璃卡片。

### 7.3 简约 Minimal

- 无封面、无背景图，只有居中歌词 + 底部控件，主背景为主题底色（C4）。
- 可选显示一行「歌名 · 歌手」小字。

### 7.4 歌词区通用规则

- 当前行居中滚动（`scroll-behavior: smooth`，用 `transform` 位移比 `scrollTop` 更顺滑）。
- 无歌词时展示占位：「暂无歌词」+「打开所在文件夹」。
- 点击某行 → 跳转到对应时间点。

## 7.5 实现补充说明（编码阶段确认的细节）

1. **CSP 与动态样式**
   `index.html` 的 CSP 为 `style-src 'self' 'unsafe-inline'`。
   原因：Chromium 会把「JS 动态创建 `<style>`」「`<style>.textContent`」「`blob:` 样式表」以及部分 CSSOM 写入判定为内联样式并拦截，而本项目的主题切换、毛玻璃强度滑杆、用户自定义主题都需要运行时改样式。
   即便如此，代码仍保持「结构里不写样式」：HTML 中零 `style` 属性，所有视觉都在 CSS 文件里，动态部分只改**设计令牌**与滑杆位置这类必要值。
   运行时令牌统一走 `js/runtime-tokens.js` 的 `setRuntimeToken()`（往预置的空 `<style id="runtime-tokens">` 里 `insertRule`），不要直接 `element.style.setProperty("--x", …)`。

2. **毛玻璃强度与主题的关系**
   模糊半径由主题令牌 `--glass-blur` 决定（深/浅极简 22px、封面取色 26px）。
   只有用户**手动拖动**过设置里的滑杆后，才用运行时令牌覆盖为自定义值（`config.glassBlurCustom` 标记），否则切主题时会被配置值「拉平」，主题自身的差异就看不出来了。

3. **「面板不透明度」滑杆**
   当前写入 `--glass-alpha` 令牌，属预留能力（内置主题未消费）。要真正生效需要在主题里用 `color-mix()` 消费该令牌，等主题规范定型后再接。

4. **窄窗口策略**
   窗口最小 1000×680。侧边栏 1120px 起收窄、1040px 起变纯图标；曲目表格按优先级隐藏列：专辑 → 拖拽手柄/更多 → 封面/爱心，行内用 0 宽度列而不是 `display:none`，保证表头与数据行始终对齐。已在 1000×608 实测无横向溢出。

5. **正在播放的音柱动画**
   通过行上的 `data-playing` 与 `aria-current` 两个属性控制 `animation-play-state`，暂停时音柱定格，不做额外 JS 动画。

## 8. 主题与样式系统（A7/A8 核心）

### 8.1 目录结构

```
frontend/src/styles/
├── index.css            # 唯一的聚合入口，按顺序 @import
├── base.css             # 复位、字体、滚动条、选中态、动画关键帧（不含颜色）
├── tokens.css           # 令牌默认值 + 语义变量到组件的映射（:root）
├── themes/
│   ├── light-minimal.css    # 浅色 · 黑白极简（随附）
│   ├── dark-minimal.css     # 深色 · 黑白极简（随附）
│   └── _template.css        # 主题模板，复制改名即可新增主题
├── components/          # 组件样式（只用令牌，不出现硬编码颜色）
│   ├── titlebar.css
│   ├── sidebar.css
│   ├── content.css
│   ├── tracktable.css
│   ├── playerbar.css
│   ├── playerview.css
│   ├── lyrics.css
│   ├── settings.css
│   └── modal.css
└── utilities.css        # 少量原子类（.u-hidden/.u-drag/.u-scroll…）
```

用户新增主题：把 `themes/_template.css` 复制为 `themes/my-theme.css`，改 `:root[data-theme="my-theme"]` 里的令牌即可；程序启动时扫描 `themes/` 目录自动列出主题，无需改任何 JS/HTML。

### 8.2 令牌契约（主题作者只需管这些）

```css
:root[data-theme="dark"] {
  /* —— 表面与层级 —— */
  --bg-app:            #0a0a0b;  /* 应用底色 */
  --bg-canvas:         radial-gradient(...);  /* 背景光斑层 */
  --surface-1:         rgba(255,255,255,.04);
  --surface-2:         rgba(255,255,255,.07);
  --surface-3:         rgba(255,255,255,.11);
  --surface-hover:     rgba(255,255,255,.06);
  --surface-active:    rgba(255,255,255,.10);

  /* —— 毛玻璃 —— */
  --glass-bg:          rgba(22,22,24,.62);
  --glass-bg-strong:   rgba(16,16,18,.78);
  --glass-blur:        22px;
  --glass-saturate:    1.6;
  --glass-border:      rgba(255,255,255,.10);
  --glass-highlight:   linear-gradient(180deg, rgba(255,255,255,.10), transparent 40%);
  --glass-shadow:      0 8px 32px rgba(0,0,0,.45);

  /* —— 文字 —— */
  --text-1: #f5f5f7;  --text-2: rgba(245,245,247,.68);
  --text-3: rgba(245,245,247,.42);  --text-inverse: #101012;

  /* —— 描边与分隔 —— */
  --border-1: rgba(255,255,255,.08);
  --divider:  rgba(255,255,255,.06);

  /* —— 强调色（黑白极简：以明度对比代替彩色）—— */
  --accent:        #ffffff;
  --accent-weak:   rgba(255,255,255,.14);
  --accent-text:   #0b0b0c;
  --heart:         #ff4d6d;   /* 唯一的彩色点缀，可被主题去掉 */

  /* —— 状态 —— */
  --danger: #ff5a5f;  --success: #3ddc84;  --warning: #ffcf5c;

  /* —— 圆角 / 间距 / 字号 —— */
  --r-xs: 6px; --r-sm: 10px; --r-md: 14px; --r-lg: 20px; --r-full: 999px;
  --sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px; --sp-5: 24px; --sp-6: 32px;
  --fs-xs: 11px; --fs-sm: 12px; --fs-md: 13px; --fs-lg: 15px; --fs-xl: 20px; --fs-2xl: 28px;

  /* —— 尺寸（布局固定）—— */
  --h-titlebar: 36px;  --w-sidebar: 232px;  --h-playerbar: 88px;  --h-header: 64px;
  --row-h: 56px;  --row-h-compact: 44px;

  /* —— 动效 —— */
  --dur-fast: 120ms;  --dur: 200ms;  --dur-slow: 420ms;
  --ease: cubic-bezier(.22,.61,.36,1);

  /* —— 层级 —— */
  --z-bg: 0; --z-content: 10; --z-playerview: 30; --z-playerbar: 40; --z-modal: 60; --z-titlebar: 70;
}
```

- **浅色主题**同名文件 `light-minimal.css`，只改上述值（`--glass-bg: rgba(255,255,255,.72)`、`--text-1:#111`、`--accent:#111` 等）。
- 主题可以不完整：缺失令牌由 `tokens.css` 的默认值兜底。
- 切换主题只改 `document.documentElement.dataset.theme`，配合 `--dur` 做 200ms 交叉过渡（`html { transition: background-color, color }`）。

### 8.3 为什么这样能满足 A7/A8

- HTML 里没有任何 `style`/`<style>`；组件 CSS 里没有硬编码颜色，全部 `var(--…)`。
- 新增主题 = 新增一个 CSS 文件 + 一条 `@import`（或由 Wails 后端把主题目录挂载后动态 `link` 注入，便于真正「丢文件即生效」）。
- 主题文件只声明变量，改不动布局，因此「布局固定」不会被主题破坏。

## 9. 交互细节清单（实现时逐条对照）

| 交互 | 行为 |
| --- | --- |
| 单击曲目行 | 立即播放并把当前视图作为播放上下文 |
| 双击曲目行 | 播放并进入播放界面 |
| 爱心按钮 | 切换「我喜欢」；列表内即时回显，无需刷新 |
| 拖拽排序 | 仅播放列表视图；拖动时显示插入位指示线；松手即持久化 |

## 10. 本次待你确认的设计点
