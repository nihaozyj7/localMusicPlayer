**第一个正式版本。** localMusicPlayer 是一个 Windows 桌面音乐播放器：**本地曲库为主，在线能力可选** ——
在线搜索 / 试听 / 下载 / 封面与歌词匹配没有一个在必经路径上，断网时它仍是一个完整的离线播放器。
绿色版单 exe，双击即用，不需要安装。

> 命名：仓库 / 项目全名 **localMusicPlayer**，中文名 **本地音乐播放器**，
> 应用标题与可执行文件是 **LMPlayer** / `lmplayer.exe`。

## 功能一览

### 曲库

- **多文件夹 + 实时监听**：递归监听音乐文件夹，新增 / 删除 / 重命名后自动增量重扫；
- **过滤规则**：按文件大小或正则（同时匹配路径与文件名）过滤，编辑时实时预览会滤掉多少；
- **标签与封面**：读取 mp3 / m4a / flac / ogg 的标签与**多张内嵌封面**；
- **稳定 ID**：同一路径永远得到同一个 id，重扫后歌单 / 收藏 / 队列不会失效。

### 播放

- **音频在后端出声**：由 Go 侧的 WASAPI 引擎在独立线程播放，前端不出声，切歌与 seek 不经过浏览器内核；
- 本地音频 HTTP 服务（`127.0.0.1` + token），原生格式支持字节级 `Range` 精确 seek；
- **内嵌 FFmpeg 8.1.2**（本项目自行编译的精简版，约 6MB）：`ape` / `wma` / `dsf` 等 WebView 放不了的格式
  转成 PCM/WAV 播放，转码结果按文件缓存；
- **响度均衡**：EBU R128（`loudnorm`）测量 + 回放增益补偿，可以逐曲，也可以同专辑统一；
- **跳过首尾静音**（默认开）：现场录音开头的空白、CD 抓轨拖在尾巴上的静音都会被掠过；
  歌曲长度、进度条与歌词仍按**原曲**呈现，只是那两段不被播放；
- **切歌间隔**：自动切下一首时留出的停顿，默认 1 秒，可调 0~10 秒；
- **音效**：清澈人声 / 低音增强 / 3D 环绕（声像与早期反射会随时间绕着头转，不是静态加宽），
  切档约 30ms 平滑过渡；
- **坏歌不卡住你**：播放失败会提示并自动跳到下一首，连续失败到阈值就熔断，只有你亲手点播才会再试；
- 播放队列拖拽排序、歌单、我喜欢、定时停止、可自定义快捷键、最小化到托盘。

### 封面

- 一首歌可以有多张封面：缓存里的（可增删 / 切换 / 轮播）与文件内嵌的（只读展示）分开管理；
- 联网匹配聚合 iTunes / 网易云音乐 / QQ 音乐 / Deezer / MusicBrainz 五个来源；
- 匹配结果可以一次性写回歌曲文件（m4a 的多个 `covr`、flac 的多个 `PICTURE`），写盘走「临时文件 + 原子改名」；
  遇到无法安全同步偏移的容器结构就放弃写入并保持原文件一个字节不动。

### 歌词

- **四级回退**：文件内嵌 → 同目录 `.lrc` → 程序缓存 → 在线自动匹配（LRCLIB / 网易云 / QQ 音乐 / 酷狗音乐）；
- **字级（逐字）歌词**：认增强 LRC / QRC / KRC / 网易云 klyric·YRC 五种写法并统一成增强 LRC，
  详情页按字点亮；本地只有行级歌词时会在后台去找一份逐字的（找到才替换）；
- **歌词工作台**：在线匹配 / 整首微调（±10s）/ 一边播放一边按空格手动打轴；
- **桌面歌词**与**桌面背景歌词**：独立的透明置顶窗口，位置会被记住，两者在底栏「选项」里三选一。

### 在线能力（都可选）

- 搜索 / 试听 / 下载（哔哩哔哩公开 Web 接口），下载文件落在你指定的目录；
- 试听缓存放系统临时目录，**空闲 7 天后自动回收**；设置 → 在线歌曲里也有「清理未引用的缓存」按钮
  —— 还在播放列表、歌单或「我喜欢」里的会保留，正在播放的那首也保留（清完会告诉你保留了几个）；
- **收藏即下载**：把「只有试听缓存」的在线歌曲加进「我喜欢」或某个歌单时，自动补一份本地文件；
- **可选 AI 清洗**：填自己的 OpenAI 兼容接口，用来清理元数据、下载后整理并回写标签
  （不填 Base URL 与 API Key 就不会联网）。

### 界面

- **主题**：内置深色极简 / 浅色极简 / 封面取色，也可以放一份 CSS 自定义主题；
  标题栏的太阳 / 月亮按钮按设置里那份主题列表**循环**切换；
- **播放界面样式插件**：内置**经典 / 沉浸**两款，第三方样式包放进数据目录即可加载，与内置走**同一条**加载路径；
  插件 CSS 由宿主强制包进 `@layer` + `@scope(舞台)`，碰不到标题栏 / 底栏 / 播放队列；
- 排序（7 个字段 × 升降序）、列表密度、列显示、动画速度、播放界面背景帧率档位都可以调。

## 系统要求

- Windows 10 1809+ / Windows 11（x64）
- [WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/) —— Windows 11 与较新的 Windows 10 已预装

首次运行会在数据目录解包内嵌的 FFmpeg：

```text
%APPDATA%\LocalMusicPlayer\             配置、曲库缓存、歌词与封面缓存、在线来源台账
%LOCALAPPDATA%\LocalMusicPlayer\bin\    解包出来的 ffmpeg.exe（可以直接替换）
%TEMP%\LocalMusicPlayer\online\         在线试听的音频缓存（可随时删除，空闲时会自动回收）
```

## 从旧版本升级

直接覆盖 `lmplayer.exe` 即可，配置、歌单、曲库缓存与下载都在原处，不受影响。
