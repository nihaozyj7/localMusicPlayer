# v1.0.3

## 新增

- **列表切换过渡动画**：在「本地歌曲 / 我喜欢 / 歌单 / 播放列表」之间切换时，内容区做一次交叉淡出淡入，标题栏、侧栏和底部播放栏保持不动；系统开启「减少动效」或环境不支持时直接切换，不做动画。
- **在线搜索遮罩铺满内容区**：搜索弹层的遮罩现在从标题栏下方一直铺到窗口底部（覆盖播放控件栏），点面板外任意位置即可关闭。
- **新播放界面样式「律动方块」**：铺在透视地面上的 3D 方块矩阵频谱，横向是频率轴、纵深是约 0.7 秒的频谱瀑布，柱高只由真实频谱能量驱动；可在「播放界面样式」里安装。

## 改进

- 播放列表的拖拽手柄改为浮层，序号列与本地歌曲、我喜欢等列表完全对齐（不再多出一列间距）。
- 在线搜索 / 试听遇到瞬时失败（取签名失败、上游 5xx 与限流、连接被对端关闭）自动重试，不再一次抖动就直接报错；确定性错误不重试。
- 播放位置防回退：逐字歌词不再周期性「取消高亮再重新点亮」，进度条与歌词跟随的后端位置保持单调，用户主动拖动 / 切歌仍立即生效。
- 播放器控件配色改为中性字色，在各主题下更协调。

## 说明

- 逐字歌词、皮肤契约（`SKIN_API_VERSION = "3.0"`）与配置键保持兼容，无需迁移。
