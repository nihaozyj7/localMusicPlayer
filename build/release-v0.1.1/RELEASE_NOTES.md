第二个公开版本。这一版主要补上「播放失败」这条容易被忽略的路径 —— 坏文件不再让播放器卡住或反复弹错，
而是自动记录、跳过并可以在设置里查看与清理。

> 命名：仓库 / 项目全名 **localMusicPlayer**，中文名 **本地音乐播放器**，
> 应用标题与可执行文件是 **LMPlayer** / `lmplayer.exe`。

## 本版新增

- **播放失败自动跳过**：文件损坏或无法解码时，不再弹一堆错误提示，而是自动切到下一首，播放不中断。
- **失败文件清单**：这些文件会被标记为「不可播放」，可从曲库中移除；设置页能看到扫描结果和详细清单，方便回头去修复或删除源文件。
- **系统媒体键支持**：键盘上的播放 / 暂停 / 上一首 / 下一首现在可以直接控制播放器；同时上报播放状态，未挂载监听时按键不会被静默吞掉。
- **歌词时间偏移**：支持整首微调歌词偏移（分 / 秒 / 毫秒），手动打轴之后对不齐的情况可以就地校正。
- **桌面背景歌词启动开关**：设置里新增「启动时自动启用」，关掉它就只在当次会话生效。
- **窗口图标修复**：绕开 Wails v3 beta 在 Windows 上图标为空实现的问题，窗口与任务栏能正确显示图标。

## 体验与修复

- **消除启动首帧黑屏**：桌面背景歌词是重量级窗口，改为推迟到主窗口露面后再创建，不再和主窗口争抢启动阶段的 CPU / GPU；桌面歌词这类轻量窗口仍保持尽早创建。
- **播放界面样式包精简**：内置样式从六种收敛为五种，移除「游戏风」(arcade) 与「舞台」(stage)；`arcanum` 样式重做，新增独立模块。
- **二次元手绘主题**：两栏布局调整，封面移到标题正上方居中，太阳放射线改为以太阳为圆心绘制。
- **后端安全加固**：新增同源请求判断，收紧 HTTP 流客户端的访问范围。

## 系统要求

- Windows 10 1809+ / Windows 11（x64）
- [WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/) —— Windows 11 与较新的 Windows 10 已预装

首次运行会在数据目录解包内嵌的 FFmpeg：

```text
%APPDATA%\LocalMusicPlayer\             配置、曲库缓存、歌词与封面缓存
%LOCALAPPDATA%\LocalMusicPlayer\bin\   解包出来的 ffmpeg.exe（可以直接替换）
```

## 从旧版本升级

直接覆盖 `lmplayer.exe` 即可，配置与曲库缓存都在数据目录里，不受影响。

第一次启动会自动把旧的 `%APPDATA%\MusicPlayer` 整体改名成 `%APPDATA%\LocalMusicPlayer`。
