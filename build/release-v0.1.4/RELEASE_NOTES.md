第四个公开版本。这一版**移除了两个混响音效**、重做了 **3D 环绕**（此前的参数在耳机上几乎听不出效果），
并修好了**播放选项面板里桌面歌词三选一不高亮当前项**的问题。

> 命名：仓库 / 项目全名 **localMusicPlayer**，中文名 **本地音乐播放器**，
> 应用标题与可执行文件是 **LMPlayer** / `lmplayer.exe`。

## 修复

- **3D 环绕戴耳机听不出效果**。原来的参数在扬声器上勉强能听出一点变化，戴耳机几乎完全无效。
  根因有两个：一是**串扰（crossfeed）的方向与环绕相反** —— 它把左右声道互相混合、缩小声道差，
  与「加宽」互相抵消，而原参数恰好把两者同时开大；二是 Haas 延迟只混入**一次**延迟信号、量也偏小，
  在耳机上很容易被听成「右边多了一点声音」而不是包围感。现在串扰从 `0.2` 降到 `0.06`，
  宽度提到 `0.98`、Haas 提到 `0.8`（延迟 15ms → 22ms），
  并给 Haas 延迟线加了**衰减反馈** —— 单次延迟变成一串间隔 22ms 的衰减重复声，
  这才是耳机上真正能制造「声音在头外面」的机制。
  实测单声道素材的声道差从 `0.085` 提到 `0.236`（约 2.8 倍），最大逐样本变化从 `0.132` 到 `0.341`。
- **选项面板里桌面歌词三选一不高亮当前项**。这是**按钮标记与 CSS 选择器的属性名对不上**：
  桌面歌词那组按 ARIA 规范用 `aria-checked`（`role="radio"`），而选中态样式只写了
  `[aria-pressed="true"]`（那是音效档位那组用的）。功能一直正常，但用户看不出当前选的是哪一档。
  现在两条选择器都覆盖。

## 变更

- **移除「现场感」与「大厅混响」两个音效档位**。音效只剩四档：
  关闭 / 清澈人声 / 低音增强 / 3D 环绕。
  **老配置不受影响**：如果配置里存着 `live` 或 `hall`，启动时会被自动收敛成「关闭」，
  不会出现「界面上一个按钮都没选中、但声音被处理过」的状态。
- 混响实现（`effects_reverb.go`）**保留未删**：当前没有任何档位引用它、处于整块旁路状态，
  但它承载的「`runReverb` 必须随 preset 一起固化」是踩过坑留下的约束，删掉等于把约束一起删了。

## 验证

- `go test -race . ./internal/... ./tools/...` 全绿；`go vet` 无告警。
- 前端 206 项测试全通过，eslint 与 tsc 干净。
- 针对上面两个修复各加了**回归测试**，并验证过它们在修复前确实会失败：
  - `TestSurroundPresetStrongEnoughForHeadphones` 测的是**感知量级**而不是「有没有变化」——
    原有的测试门槛只有 `> 0.02`，修复前的错误参数实测能到 `0.13`，轻松通过却听不出来，
    所以那条测试**抓不住**这个问题。新增的测试把门槛提到听感可辨的量级。
  - `TestSurroundCrossfeedStaysSmall` 直接约束串扰不能调大（它的破坏方式很隐蔽）。
  - `分段控件的选中高亮同时覆盖 aria-pressed 与 aria-checked` 钉住标记与样式两端。

## 系统要求

- Windows 10 1809+ / Windows 11（x64）
- [WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/) —— Windows 11 与较新的 Windows 10 已预装

首次运行会在数据目录解包内嵌的 FFmpeg：

```text
%APPDATA%\LocalMusicPlayer\             配置、曲库缓存、歌词与封面缓存
%LOCALAPPDATA%\LocalMusicPlayer\bin\   解包出来的 ffmpeg.exe（可以直接替换）
%TEMP%\LocalMusicPlayer\online\        在线试听的音频缓存（可随时删除）
```

## 从旧版本升级

直接覆盖 `lmplayer.exe` 即可，配置与曲库缓存都在数据目录里，不受影响。
若此前选过「现场感」或「大厅混响」，升级后音效会自动变成「关闭」——这两个档位已移除。
