# v1.0.2

## 新增

- **大曲库窗口化渲染**：曲库超过 300 首时只渲染可视区域附近的行，滚动与切歌明显更流畅；队列仍全量渲染，拖拽排序不受影响。
- **转码缓存跟随「缓存目录」**：缓存目录改到哪里，转码产物就落到哪里，旧位置会自动清理。

## 修复

- 播完自动切下一首时偶尔不播放、没有声音。
- 后端无响应时可能永久卡在「切歌中」或启动卡死：启动探测 12 秒、切歌 7 分钟超时后自动恢复，且不会把正常文件误判为坏文件。
- 长列表里「定位到当前播放」会误报歌曲不在列表。
- 续播进度裁剪错误，常听的老歌反而先丢进度。
- 切换响度挡位会丢掉其它挡位已算好的增益，来回切要反复重算。
- 「清空转码缓存」漏清进程被强杀后留下的 `.pcm` / `.part` 中间文件。
- 应用内更新下载的安装包带 `.part1` 后缀，双击无法运行。
- 同名歌曲从试听缓存下载时会互相覆盖。
- 取消收藏最后一首后，歌曲仍留在「我喜欢」列表。
- 连续重扫样式会残留重复的 `<style>`，移除或更新样式后旧样式仍然生效。
- 拖动桌面歌词窗口后，位置偶尔没有保存。
- 扫描大量小 m4a 文件时每首多分配 2 MB 内存；异常的逐字歌词解压可能占用数 GB 内存（现限制在 4 MB 内）。
