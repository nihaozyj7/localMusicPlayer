# v1.0.1

一次小更新：新增歌单与队列的数量统计，修复中文路径下自动更新失败，并换上新图标。

## 新增

- **歌单与队列的数量统计**：侧边栏的歌单、底栏的队列徽标、歌单详情页的标题都会显示歌曲数量，
  且只数**当前真的存在**的歌。

## 修复

- **中文路径下自动更新失败**：安装脚本不再把路径写进 cmd 脚本文本，改为用环境变量传递，
  中文用户名目录（`C:\Users\中文名\…`）下不会再因控制台代码页差异把路径解析错。
- **应用内「检查更新」挑不到安装包**：发布资产改用带 `windows-x64` 的规范文件名，
  更新检查能正确匹配到安装包（此前会提示「没有提供当前平台(Windows x64)的安装包」）。
- **歌单数量虚高**：歌单里指向已删除文件的失效引用不再计数，也不会被塞进播放队列
  （此前会出现「标题写 19 首、列表只有 14 行」，以及队列里跳到一首空歌）。
- **队列徽标不刷新**：删掉歌曲后，队列徽标立刻按实际可播放的数量更新，不再只认队列长度。

## 变更

- 应用图标换成更高分辨率的新版本（窗口 / 任务栏 / exe 图标）。

## 系统要求与升级

- Windows 10 1809+ / Windows 11（x64），需要 [WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)（新系统已预装）。
- 直接覆盖旧的 `lmplayer.exe` 即可，配置、歌单、曲库缓存与下载都留在原处；
  应用内「设置 → 关于 → 检查更新」也能直接更新到本版。
