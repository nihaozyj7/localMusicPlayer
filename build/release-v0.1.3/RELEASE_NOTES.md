第三个公开版本。这一版修好了**在线试听**（此前一首完全正常的在线歌曲会被误判成坏文件而无法播放），
补上了**列表排序的升序 / 降序**，并让程序可以**自己检查与安装更新**。

> 命名：仓库 / 项目全名 **localMusicPlayer**，中文名 **本地音乐播放器**，
> 应用标题与可执行文件是 **LMPlayer** / `lmplayer.exe`。

## 修复

- **在线试听重新可用**。此前在线曲目只存在于前端，后端曲库里没有它，解析必然失败；
  而这条失败被当成「文件损坏」处理 —— 于是一首完全正常的在线歌曲会被登记进「放不出来」清单
  并从列表里摘掉，表现就是「在线试听不能用了」。现在试听的音频会**同步缓存到本地**，
  后端因此有一个真实的文件可以解码播放。
- **排序的降序是反的**。`添加时间` 与 `播放次数` 的比较函数自身已写成降序，与「降序」方向叠加后
  互相抵消 —— 选「降序」看到的却是最旧的排在前面。现在比较函数一律只用升序语义，
  方向完全由用户选择决定。
- **下载不再重复消耗流量**。试听过的歌在本地已有完整音频，点下载时直接从缓存搬到下载目录。

## 本版新增

- **试听即缓存**：试听时音频边播放边落盘（缓存放在系统临时目录，**不进下载目录、也不进曲库扫描**）。
  缓存是可丢弃的派生数据，被系统清理后下次试听会自动重新下载。
- **下载优先用缓存**：命中缓存时直接把文件移动到下载目录（跨盘符自动退化为复制 + 删除），
  秒完成；搬运失败会老实回退到网络下载，不影响结果。
- **排序悬浮面板**：工具栏一个按钮打开面板，**排序方式**（添加时间 / 标题 / 歌手 / 专辑 /
  时长 / 文件大小 / 播放次数）与**排列顺序**（升序 / 降序）分开选。按钮上直接显示当前排序，
  看面板之前就知道按什么排。换字段时会套用合理默认（时间类默认降序、文本类默认升序）。
- **表头排序保留**：点「标题 / 专辑 / 时长」列头仍然可以直接切换升降序。
- **自动更新**：启动时静默检查 GitHub Release，有新版本可以一键下载并自动替换安装；
  下载支持多个代理通道自动降级（网络不通时不必手动去下载）。

## 体验与修复

- **在线曲目不再被误判为坏文件**：它的失败原因绝大多数是网络（限流 / 无版权 / 临时抽风），
  不该被永久拉黑。前后端各挡一层，确保它不会被写进「放不出来」清单。
- **排序面板无障碍**：当前选中的字段与方向带 `aria-checked`，读屏用户能知道选的是哪个。
- **修掉一个文件句柄泄漏**：下载重名探测时 `.part` 占位文件的句柄没有被关闭，
  会在音乐目录里留下一个**删不掉**的 0 字节文件。
- **在线试听失败不再触发曲库摘除**：不会再出现「点了首歌，列表里它却消失了」。

## 系统要求

- Windows 10 1809+ / Windows 11（x64）
- [WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/) —— Windows 11 与较新的 Windows 10 已预装

首次运行会在数据目录解包内嵌的 FFmpeg：

```text
%APPDATA%\LocalMusicPlayer\             配置、曲库缓存、歌词与封面缓存
%LOCALAPPDATA%\LocalMusicPlayer\bin\   解包出来的 ffmpeg.exe（可以直接替换）
%TEMP%\LocalMusicPlayer\online\        在线试听的音频缓存（可随时删除）
```

## 从旧版本升级

直接覆盖 `lmplayer.exe` 即可，配置与曲库缓存都在数据目录里，不受影响。

第一次启动会自动把旧的 `%APPDATA%\MusicPlayer` 整体改名成 `%APPDATA%\LocalMusicPlayer`。
